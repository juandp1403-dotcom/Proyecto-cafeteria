# Manual del Cajero

## Permisos

El cajero puede consultar dashboard, productos, ventas, compras y reportes. Puede aceptar o rechazar ventas y generar reportes, pero no puede crear, editar ni eliminar productos, registrar compras ni administrar usuarios.

## Revisar el dashboard

Abra **Dashboard** para consultar ventas del día, ventas recientes, productos con poco stock y productos agotados.

## Gestionar pedidos

1. Abra **Ventas**.
2. Revise el cliente, los productos, el valor y el estado del pedido.
3. Para un pedido en `Pendiente de Pago`, seleccione **Aceptar** o **Rechazar**.
4. Si lo rechaza, el sistema devuelve las unidades al stock.
5. Puede marcar el pedido como `Preparado` o `Entregado` cuando el proceso de la cafetería lo requiera. El despachador solo puede marcarlo como `Entregado`.

## Consultar productos y compras

Puede consultar el catálogo de productos y el historial de compras. Las acciones que cambian el inventario están reservadas para el administrador.

## Generar reportes

Entre a **Reportes** para consultar los reportes disponibles y generar los que permita la pantalla. Los datos personales de clientes se muestran protegidos o enmascarados cuando corresponda.

## Restricciones

El cajero no puede acceder a **Usuarios** ni a **Auditoria**, no puede modificar el catálogo y no puede registrar compras o bajas de inventario.
