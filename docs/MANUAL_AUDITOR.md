# Manual del Auditor

## Permisos

El auditor tiene acceso de solo lectura a dashboard, productos, ventas, compras, reportes, usuarios y auditoria. No puede crear, editar, eliminar, reactivar ni cambiar estados.

## Revisar información

- Consulte **Dashboard** para revisar indicadores generales.
- Consulte **Productos** para verificar catálogo y estado del stock.
- Consulte **Ventas** y **Compras** para comparar operaciones.
- Consulte **Reportes** para revisar los informes registrados.
- Consulte **Usuarios** para verificar cuentas y roles.

## Consultar auditoria

1. Abra **Auditoria**.
2. Revise usuario, acción, entidad, detalle y fecha.
3. Use la información para identificar cambios o actividades que requieran seguimiento.

## Protección de datos

El auditor no puede ver datos personales completos. Los nombres se presentan mediante iniciales, los documentos se enmascaran y los correos se ocultan. Esta restricción es intencional y debe respetarse.
