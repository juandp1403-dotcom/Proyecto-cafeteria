# Manual del Cliente Comprador

## 1. Identificarse

El cliente no necesita crear una cuenta con contraseña. Para iniciar un pedido:

1. Abra la pagina de la cafeteria.
2. Escriba su numero de documento.
3. Escriba su nombre completo.
4. Escriba su numero de ficha.
5. Lea la politica de privacidad y marque la autorizacion para el tratamiento de datos.
6. Seleccione **Ver Menu**.

Si el documento ya estaba registrado, el nombre y la ficha deben coincidir con el registro anterior. Si no coinciden, solicite ayuda a un cajero.

## 2. Elegir productos

1. Seleccione una categoria.
2. Revise los productos disponibles y sus precios.
3. Indique la cantidad de cada producto.
4. Revise el carrito y el total.
5. Seleccione el metodo de pago: efectivo, tarjeta o transferencia.
6. Seleccione **Confirmar pedido** una sola vez.

El sistema valida que haya stock disponible. Si el stock cambia antes de confirmar, se mostrara un mensaje y deberá ajustar el pedido.

## 3. Consultar el pedido

Después de confirmar, el sistema muestra el numero del pedido y su estado. Conserve ese numero para consultar la compra.

Estados posibles:

- `Pendiente de Pago`: el pedido fue recibido y espera validacion.
- `Pagado/Preparando`: el pedido fue aceptado y esta en preparacion.
- `Preparado`: el pedido esta listo para recoger.
- `Entregado`: el pedido fue entregado.
- `Cancelado`: el pedido fue cancelado.

La pantalla de estado se actualiza automaticamente mientras el pedido avanza.

## 4. Cancelar un pedido

El cliente puede cancelar su propio pedido solamente mientras este en estado `Pendiente de Pago`:

1. Abra la pantalla de estado del pedido.
2. Seleccione **Cancelar pedido**.
3. Confirme la cancelacion.

Cuando la cancelacion es aceptada, el stock reservado se devuelve. Un pedido que ya fue aceptado, preparado, entregado o cancelado no puede cancelarse desde el portal.

## 5. Ver la factura

Desde la pantalla del pedido puede consultar el detalle de productos, cantidades, precios, total, fecha y metodo de pago. La factura solo esta disponible para el propietario del pedido o para un usuario administrativo autorizado.

## 6. Privacidad y salida

- Use **Politica de privacidad** para consultar el tratamiento de sus datos.
- Use **Solicitar supresion** si desea pedir la eliminacion o anonimizacion de sus datos.
- Al terminar, seleccione **Salir** para cerrar la identificacion en el equipo.
- No comparta su documento, ficha ni el enlace de seguimiento con otras personas.

## 7. Recomendaciones

- Verifique nombre, cantidades y total antes de confirmar.
- No recargue ni presione varias veces el boton de confirmacion.
- Si aparece `Stock insuficiente`, reduzca la cantidad o elija otro producto.
- Si la sesion expira, vuelva a identificarse para iniciar un nuevo pedido.
